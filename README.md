# qa_python

## Финальный проект 4 спринта: Тестирование BooksCollector

Проект содержит автотесты для проверки функциональности класса BooksCollector.

### Список реализованных тестов:

1. test_add_new_book_add_valid_name_length — проверка успешного добавления книг с граничной и допустимой длиной названия: 1, 20 и 40 символов (параметризованный тест).
2. test_add_new_book_add_same_book_not_added — проверка того, что одну и ту же книгу нельзя добавить дважды (дубликаты игнорируются).
3. test_set_book_genre_valid_genre_success — проверка успешной установки корректного жанра из разрешенного списка для добавленной книги.
4. test_get_book_genre_positive — проверка корректного получения жанра книги по ее названию.
5. test_get_books_with_specific_genre_in_genre_list — проверка фильтрации и возврата списка книг по заданному жанру.
6. test_get_books_genre_one_book_in_dictionary — проверка корректного возврата всего текущего словаря добавленных книг и их жанров.
7. test_get_books_for_children_genre_age_rating_not_added — проверка того, что книги с возрастными ограничениями (жанры «Ужасы» и «Детективы») не попадают в список книг для детей (параметризованный тест).
8. test_add_book_in_favorites_success — проверка успешного добавления книги из общего списка в избранное.
9. test_add_book_in_favorites_cannot_add_same_book — проверка того, что одну и ту же книгу нельзя добавить в список избранного повторно.
10. test_delete_book_from_favorites_success — проверка успешного удаления книги из списка избранного.
11. test_get_list_of_favorites_books — проверка получения актуального списка избранных книг.

### Запуск тестов:
pytest -v tests.py
